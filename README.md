# cmvsalto.github.io — Custos & Fichas Salto

Fichas técnicas, CMV e preços do Salto das Nuvens. Abra no Chrome ou Edge e use "Instalar app" para ter no computador.

Os dados não ficam neste repositório: na primeira abertura, carregue o backup (.json) exportado em "Dados e backup". Depois disso eles ficam salvos no próprio computador.
