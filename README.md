# Custos & Fichas Salto

Fichas técnicas, CMV e preços do Salto das Nuvens. Abra no Chrome ou Edge e use "Instalar app" para ter no computador.

Os dados ficam em dados.enc.json, criptografados com a senha do login (AES-GCM). Sem a senha, o arquivo não pode ser lido. Na primeira abertura o app descriptografa e guarda os dados no próprio computador.
